全局设置
全局路径前缀截断
按路径段数量截断前缀，列表、路径复制和精简请求共用此设置。默认 0 段，保留完整路径。
列表展示 Query 参数
默认不展示；Query 参数仍可在下方请求参数区域查看。
重复请求警告
比较设定间隔内请求的方法、过滤后 URL 和请求体。上传文件内容不完整时，匹配项标记为可能重复。默认 1000 ms。
过滤 Query 参数
多个参数名用逗号分隔，展示和复制时都会移除。默认过滤 _t。
排除接口
多个路径用逗号分隔，按 URL 路径精确匹配，不受 Query 参数影响。
常用预设

选择预设填入常用字段和成功值，可继续编辑，保存后生效。

字段支持点号路径；留空可忽略该类检查。成功状态码用逗号分隔。保存后对当前及后续请求生效，HTTP 状态独立判断。

显示与过滤设置即时生效；业务规则保存后生效。

快捷键与操作
在未编辑输入框、且没有文字选区时生效
↑↓焦点在接口列表时，上下切换选中请求
C复制“路径 + 参数”；POST / PUT / PATCH / DELETE 会同时带 Body
⌘ C或Ctrl C复制精简请求 + 响应
鼠标框选可以直接选择接口列表中的任意文字，再用系统复制命令复制选区
鼠标悬浮接口行右侧出现 3 个高频快捷按钮：路径、路径+参数、精简请求
提示：搜索框、Query 参数配置框或 Preview 搜索框获得焦点时，字母快捷键不会触发。
