# 面板代码结构

源码直接作为扩展运行文件，不增加框架、构建步骤或远程脚本依赖。模块使用普通脚本与明确的公共接口；有 UI 状态的功能通过工厂传入必要回调，不相互读取内部状态。

| 文件 | 职责 |
| --- | --- |
| panel.js | DevTools 请求采集、选中记录、列表更新、详情协调与布局 |
| src/i18n.js | 文案、本地网页预览回退和静态标签翻译 |
| src/json.js | 无损 JSON 解析、类型识别和字段复制格式 |
| src/request-data.js | HAR 参数与 Body 解析、Token 提取、cURL 格式；不读取 DOM |
| src/json-tree.js | 响应与 Body 共用的 JSON 树、折叠摘要、数组分组与搜索路径索引 |
| src/request-filters.js | 方法、HTTP／业务失败、慢请求筛选条件和对应控件 |
| src/business-rules.js | 业务规则验证、存储、纯响应判定及设置表单 |
| src/panel-ui.js | 设置抽屉与分类导航、剪贴板兼容处理和按钮反馈；不读取请求数据 |
| src/request-controls.css | 新控件样式，复用 panel.css 的颜色、边框、字号等主题变量 |
| vendor/ | 固定版本的本地第三方库和许可证 |

加载顺序在 panel.html 中明确声明：先解析库、文案和 JSON 基础模块，再加载请求数据、树、筛选和业务规则，最后运行入口。打包脚本使用白名单，包含 src 和 vendor，不包含 tests、fixtures 或商店素材。

## 状态和更新边界

- 请求与响应正文按原样保留。显示、筛选、状态判断及复制格式分开处理。
- 快捷筛选只决定列表可见行，不删除采集记录，也不重建当前 Preview。
- HTTP 失败指状态码 0 或不小于 400。业务失败来自用户配置；同时开启两类失败筛选时取并集，与方法／慢请求筛选取交集。
- 业务规则先编辑草稿，通过验证并成功保存后才生效。保存复用已解析响应重新判定现有记录，只更新列表与详情状态文案。
- 显示与过滤仍即时生效；设置抽屉仅改变可见分类和焦点，不参与请求或 JSON 的重建。
- 复制入口传入触发按钮，成功只替换图标，保持文案和按钮尺寸。两种剪贴板入口均失败才显示错误提示。六个工具栏复制操作直接并列，窄屏统一隐藏文字。
- 紧凑尺寸集中定义在 panel.css 的主题变量中。JSON 字段、对象和请求 Body 复用同一套操作按钮样式，不追加互相覆盖的字号或内边距规则。
- Query 和 FormData 共用参数列表渲染。缺失参数分区不渲染，JSON 空值仍保留。方向键仅在列表获得焦点时切换请求，参数与响应正文保留独立焦点。
- Query、FormData 与 JSON 节点共用复制按钮样式，提供值与键值复制。数组项使用原始下标。
- 参数列表在宽面板中按列排列，在窄面板中将字段名和值分行，两个复制按钮可随内容换行。
- 「路径 + 参数」与精简请求沿用列表的路径前缀设置，并输出保留 URL 编码的路径与 Query。
- 业务预设仅填充草稿；高亮由当前字段和值推导，保存前不持久化或重判请求。success 预设不推测 errorCode 的成功值。
- 配置字段使用只读自有属性的点号路径，不执行表达式；缺失或非标量字段保持未知。任一存在的已配置检查失败，则标记业务失败。
- cURL 使用原始完整 URL 和原始 Body，不受展示截断与 Query 过滤影响。连接类、长度类及伪头交给 cURL 生成。
- multipart 按完整分隔行解析。cURL 重建表单时用 `--form-string` 输出文本，文件使用 `/path/to/` 占位路径。解析失败时按原始正文与 Content-Type 输出。

## 验证

纯逻辑测试：

    node --test tests/request-features.test.cjs

本地静态服务器运行后打开 tests/panel-regression.html。浏览器回归覆盖数值精度、重复参数、大数组搜索、阅读状态、快捷筛选、规则保存与重判、cURL 复制、中英文控件和多宽度布局。

扩展重新加载后需重新打开 DevTools。发布时保持打包白名单，并验证所有新模块和第三方许可证均包含在 ZIP 内。
