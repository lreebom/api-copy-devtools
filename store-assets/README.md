# Chrome / Edge 商店发布材料

当前安装包为 `../dist/api-copy-devtools-v0.6.0.zip`，由 `scripts/package.sh` 生成。商店材料不进入扩展安装包。

- `RELEASE_NOTES.md`：中英文更新说明，可复制到商店更新说明栏。
- `STORE_LISTING.zh-CN.md`：简体中文商品详情。
- `STORE_LISTING.en.md`：英文商品详情。
- `PRIVACY_FORM.zh-CN.md`：隐私权规范填写稿。
- `TEST_INSTRUCTIONS.zh-CN.md`：审核测试说明。
- `EDGE_CERTIFICATION_NOTES.en.txt`：英文审核说明，包含无需账号的公开接口测试步骤与 DevTools 入口。
