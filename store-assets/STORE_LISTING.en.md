# Chrome Web Store listing (English)

## Name

API Copy - Request & Response

## Summary

Review XHR/Fetch paths, parameters, and responses in one panel, then copy them without repeatedly opening requests in Network.

## Detailed description

In Chrome's Network panel, you usually select requests one at a time and switch between sections to inspect paths, Query parameters, request bodies, and responses. Copying those details also takes repeated steps. API Copy gathers XHR and Fetch requests in one list. Select a request to review its parameters and response in the same panel, then copy the details you need.

API Copy helps with frontend development, API integration, and debugging. Review request paths, parameters, and results with less back-and-forth, then share the relevant details with a teammate or an AI assistant.

Key features:

- Inspect methods, status codes, paths, timing, headers, request bodies, and responses
- Copy a path, path with parameters, concise request, full request, or Token
- Use quick-copy actions directly from request rows
- Search JSON response keys and values
- Switch between alphabetical and original JSON field order
- Expand long text and copy complete field values
- Highlight common business-level failures
- Filter Query parameters and exclude analytics or tracking endpoints
- Switch between automatic, side-by-side, and stacked layouts, with draggable panel sizing
- Use keyboard shortcuts for frequent operations
- Follow Chrome's UI language with English and Simplified Chinese interfaces

All request and response data is processed locally in the user's browser. API Copy does not upload this data to developer-operated servers or third-party services.

To use it, open Chrome DevTools on a page, select the API Copy panel, and reload the page or trigger an API request.
