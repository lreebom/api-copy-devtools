# Chrome Web Store 商品详情（简体中文）

## 名称

API Copy - Request & Response

## 简短说明

集中查看 XHR / Fetch 请求路径、参数和响应，并快速复制，减少在 Network 面板逐条打开请求的操作。

## 详细说明

在 Chrome 自带的 Network 面板中，通常需要逐条选择请求，再切换不同区域查看路径、Query、请求 Body 和响应；复制这些信息也要反复操作。API Copy 将页面产生的 XHR / Fetch 请求集中列出，选中请求后即可在同一面板查看参数与响应，并快速复制常用内容。

它适合前端开发、接口联调和问题排查：不用在 Network 请求详情间来回切换，就能更快核对接口路径、请求参数和返回结果，并把完整信息交给同事或 AI 工具分析。

主要功能：

- 查看请求方法、状态码、路径、耗时、请求头、请求体和响应内容
- 一键复制接口路径、路径与参数、精简请求、完整请求或 Token
- 在接口行内快速复制常用内容
- 搜索 JSON 响应中的字段和值
- 按字母顺序或原始 JSON 顺序查看响应字段
- 展开长文本并复制完整字段值
- 识别常见业务失败状态
- 过滤指定 Query 参数，排除埋点、统计等非业务接口
- 支持自动、左右和上下布局，并可拖动调整列表与 Preview 面板尺寸
- 支持键盘快捷操作
- 界面自动跟随 Chrome 语言，支持简体中文和英文

所有请求和响应数据仅在用户本地浏览器中处理，不会上传到开发者服务器或第三方服务。

使用方法：打开网页的 Chrome DevTools，在“API Copy”面板中刷新页面或触发接口请求，然后选择请求进行查看和复制。
