# Chrome Web Store 测试说明

## 是否需要测试账号

不需要。扩展没有登录功能，也不依赖开发者服务器。

## 测试步骤

1. 安装扩展。
2. 打开任意会产生 XHR 或 Fetch 请求的网页。
3. 打开 Chrome DevTools，选择“API Copy”面板。
4. 刷新网页或在页面中执行会触发接口请求的操作。
5. 在左侧请求列表中选择任意请求。
6. 在 Preview 中检查响应内容，并测试搜索、字段排序、展开长文本和复制按钮。
7. 使用顶部按钮测试复制路径、路径与参数、精简请求、完整请求和 Token。
8. 打开“过滤设置”，可验证 Query 参数过滤和接口路径排除功能。

## 审核说明

扩展只读取 Chrome DevTools Network API 向当前 DevTools 会话提供的 XHR / Fetch 请求。它不会向外部服务器发送采集到的请求或响应信息。
