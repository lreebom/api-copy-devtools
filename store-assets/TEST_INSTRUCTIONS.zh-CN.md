# Chrome / Edge 商店测试说明（0.5.0）

## 是否需要测试账号

不需要。扩展没有登录功能，也不依赖开发者服务器。

## 测试步骤

1. 安装扩展。
2. 打开任意会产生 XHR 或 Fetch 请求的网页。
3. 打开 Chrome DevTools，选择“API Copy”面板。
4. 刷新网页或在页面中执行会触发接口请求的操作。
5. 在左侧请求列表中选择任意请求。
6. 在 Preview 中检查响应内容，并测试搜索、字段排序、展开长文本和复制按钮。
7. 使用顶部按钮测试复制路径、路径与参数、精简请求、完整请求、cURL 和 Token（请求存在 Token 时）。
8. 打开“设置 → 过滤”，验证 Query 参数过滤和接口路径排除；在“业务规则”中选择 success 等预设并修改成功值，确认保存前不改变记录、保存后更新已采集请求的状态。
9. 验证方法、HTTP／业务失败、慢请求快捷筛选，以及 Query／FormData 的逐项复制。长字段名与长值应完整换行，不需要展开即可阅读。
10. 调整面板尺寸后双击分隔线，检查主面板恢复 40% / 60%、列表与参数恢复 65% / 35%。窄窗口下复制按钮应统一显示为图标。

## 审核说明

扩展只读取 Chrome DevTools Network API 向当前 DevTools 会话提供的 XHR / Fetch 请求。它不会向外部服务器发送采集到的请求或响应信息。

扩展没有浏览器工具栏弹窗，入口在 DevTools 内。只采集打开面板后发生的请求。无需账号的公开接口测试步骤见 [英文审核说明](./EDGE_CERTIFICATION_NOTES.en.txt)。
